# Homebrew tap for Styx

```sh
brew install --cask nicholasflemmer/styx/styx
```

[Styx](https://heystyx.com) runs coding agents (Claude Code, Codex, Gemini CLI, Cursor's agent) on all your projects at once, each on its own branch, and they ask before they touch production. Source: [NicholasFlemmer/styx-app](https://github.com/NicholasFlemmer/styx-app). Apple silicon, macOS 12 or later.

Styx updates itself once installed. To update the cask: bump `version` and `sha256` in `Casks/styx.rb`.
